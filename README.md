# 大央ハウジング 物件資料メーカー（Web版）

登記簿・物件レポート・公図・地図・写真のほか、Word・Excel・CSV・テキスト・他社の販売図面・ポータルサイトの物件ページなどを読み込み、大央ハウジングの物件概要書（物件資料）を作るWebアプリです。

- 公開先：https://md19880822-afk.github.io/daio-bukken/
- アプリ本体：`index.html`（1つのファイルにすべて入っています）
- AIは高性能モデル（Claude Opus 5.5）を使います。管理者が作る「社員用リンク」から開くと使えます。
- APIキーはこの置き場には入っていません（リンクを開いた端末のブラウザにだけ保存されます）。
- キーがなくても、登記簿・用途地域図と文字のある資料は、AIを使わない簡易読み取りで反映します。
- アピールポイントの材料として、所在地から周辺の施設・徒歩の道のり・標高を地図で調べます（無料・キー不要）。AIの設定があるときは、ネット検索で地域の特徴・開発・学校区も出典つきで調べます。
- 他社などの物件概要書・販売図面・ポータルの物件ページは、内容の読み取りにだけ使い、作る物件資料には添付しません（必要なときは✓で添付できます）。
