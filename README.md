# 大央ハウジング 物件資料メーカー（Web版・無料）

登記簿・用途地域図・公図・地図・写真のほか、Word・Excel・CSV・テキスト・他社の販売図面・ポータルサイトの物件ページなどを読み込み、大央ハウジングの物件概要書（物件資料）を作るWebアプリです。

- 公開先：https://md19880822-afk.github.io/daio-bukken/
- アプリ本体：`index.html`（1つのファイルにすべて入っています）
- 料金のかからない無料版です。有料のAI（API）は使いません。文字のある資料は、AIを使わずに「見出し：内容」の形から読み取ります。
- 物件レポートや画像の資料の読み取り、写真の選別、キャッチコピー作成などのAI機能は、claude.ai版（各自の claude.ai アカウントで利用。無料プランも可）で使えます。
